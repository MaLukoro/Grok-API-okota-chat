Management Key を入れると残量が出る

チャット用 APIキーでは残高は見えない。console.x.ai → Settings → Management Keys で、Billing が読めるキーを発行してくれ。台帳は締め後の数字で、今月の使用は usage API から引いてライブ残を出してる。

残高が弾かれたとき（中継＝Worker）

チャット用のサーバーはブラウザ直OK。残高サーバーだけ拒否する。中継は Cloudflare が無料で貸す小さいプログラムで、名前が Worker。チャットには不要。

1. https://dash.cloudflare.com に入る（無料）
2. Workers & Pages → Create → Hello World で作る
3. コードを全部消して、このフォルダの worker.js を貼る
4. Deploy
5. 出てきた https://なにか.workers.dev の後ろに /v1 を付けて
   ⚙ のプロキシURLへ。例: https://xxx.workers.dev/v1
6. 残量を更新

プロキシを入れるとチャットもそこを通る。worker.js は最新を貼れ。
中継したくなければ、残高表示は諦めてチャットだけ使えばいい。
